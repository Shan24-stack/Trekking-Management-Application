# Trekking Management Application

A Flask-based web application for managing trekking activities.

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap

## Features
- Admin Dashboard
- Trek Management
- User Registration & Login
- Staff Approval
- Trek Booking
- Booking History
- User & Staff Management

## Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```
